# The Paperclip Review — One Line, 93 Characters

Built for the [make.fun "The Most Boring Object, Reviewed in One Line" bounty](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3) — a program that writes one funny, true one-line review of the dullest everyday object: the paperclip. Join make.fun with referral code `qgn48q27`: https://make.fun/r/qgn48q27

The entry:

> The paperclip has held my life together since 2019 and still bends out of shape over nothing.

The joke is the object's own behaviour: a paperclip really does hold things together for years, and it really does bend out of shape at the slightest force — literal and idiomatic at once.

## Run

```sh
node main.ts
```

Writes `entry.txt` to the output directory (`MAKEFUN_OUTPUT_DIR`, else `output/` next to `main.ts`).
